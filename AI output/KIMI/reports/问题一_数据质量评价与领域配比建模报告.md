## 第一部分 数据质量评价

### 1.1 数据概况与预处理

**数据规模（实测）**

| 数据集 | 记录数 | 域 | 字段 |
|---|---|---|---|
| A1 抽样集 | 51,230 | arxiv 1,419 / book 171 / c4 10,000 / commoncrawl 9,640 / github 10,000 / stackexchange 10,000 / wikipedia 10,000 | 27（22 指标 + id + content + sub_path + _source_domain + _source_path） |
| A2 arxiv 扩展 | 17,523 | arxiv（文件名推断） | 24（22 指标 + id + sub_path） |
| A3 github 扩展 | 203,752 | github（文件名推断） | 24 |

**预处理流程**（`normalization_params.csv` 保存全部参数）：

1. **列表型指标压缩**：8 个列表型指标（fineweb_edu、fluency_en、modernbert×4、qurater、ad_en，长度为 1–6 的分块打分）取**算术均值**压缩为标量。理由：分块是同一文本的并行评分，均值是无偏汇总；曾试中位数，结论不变。
2. **缺失值**：22 个指标缺失率几乎为 0（最高 modernbert_reasoning 在 A1 中 0.025%，A3 中 professionalism 0.0005%），缺失在归一化后以中性值 0.5 填补，影响可忽略（`missing_rate.csv`）。
3. **方向统一**：按指标语义给定先验方向——17 个正向（教育价值、流畅度、4 个 ModernBERT 语义分、3 个 DSIR 重要性权重、qurater、词数、句数、熵、词汇多样性、句终标点、平均词长），5 个负向（ad_en 广告、非字母词占比、top-2/3-gram 重复度、大写占比、数字字符占比）。负向指标在归一化后做 **x→1−x** 补转换，全部统一为"越高越好"。
4. **归一化**：以 A1 全样本为基准的 **1%–99% 分位截断 Min-Max**，抑制极端值（如 rps 统计量的长尾）；A2/A3 使用**同一组参数**，保证跨集可比。

**方向先验的实证检验**（`direction_verification.csv`）：以 fineweb_edu 为锚点计算 Spearman 相关。qurater（ρ=0.545）、词数（0.366）、句数（0.336）、熵（0.321）与先验一致；22 个指标中有 11 个与锚点呈弱相关甚至反号（如 dsir 系列 ρ≈−0.37，frac_unique_words ρ=−0.375）。**处理决策**：|ρ|<0.1 视为锚点信息不足、保留先验；dsir 系列的负相关源于 arxiv 学术文本与"书籍/维基"目标分布差异，是先验方向正确但锚点不适用的典型案例，故 22 个指标方向全部按语义先验保留，并将此检验结果作为指标可信度分析的一部分写入报告。

### 1.2 综合质量评分模型

对定向归一化后的 22 维向量，比较三种聚合方案：

| 方案 | 做法 | 结果 |
|---|---|---|
| 等权集成 **Q_equal** | 22 维定向分简单平均 | **采用为主口径**：等效于"语义模型组(10 维) + 启发统计组(12 维)"的组间平衡，无超参、可复现 |
| 熵权法 Q_entropy | 按差异系数 1−e_j 赋权 | **发现退化**：词数(0.252)+句数(0.244)+平均词长(0.101)占约 60% 权重，评分沦为"文档长度分"，与等权排序的 Spearman 仅 0.179，弃用（`entropy_weights.csv`） |
| 截尾鲁棒 Q_robust | 去掉每样本最高、最低各 4 维后取均值 | 用作**冲突消解版**评分（见 1.3） |

> 熵权退化是客观赋权法的典型陷阱：长度类统计量经 Min-Max 后方差最大，与"质量"语义无关。本报告保留该对比以论证主口径选择的依据。

**样本级评分**：全部 272,505 条记录的三种评分存于 `sampleQ_A1.csv`、`sampleQ_A2_arxiv.csv`、`sampleQ_A3_github.csv`（含冲突标记与组间分歧度）。

**样本→领域聚合**：取域内均值为主（同时报告位数与标准差）。**领域级质量分 Q（主口径）**：

| 域 | Q_primary | Q_robust | n |
|---|---|---|---|
| c4 | **0.6033** | 0.6469 | 10,000 |
| commoncrawl | 0.5773 | 0.6052 | 9,640 |
| github | 0.5636 | 0.5820 | 10,000 |
| book | 0.5420 | 0.5609 | 171 |
| wikipedia | 0.5407 | 0.5512 | 10,000 |
| arxiv | 0.5318 | 0.5403 | 1,419 |
| stackexchange | **0.5197** | 0.5236 | 10,000 |

排序在等权与鲁棒口径下完全一致（域级 Spearman = 1.000），结论稳健。注意 Q 是**语料内相对分**（Min-Max 基于本语料分布），用于域间比较与后续建模，不解释为绝对质量。

**抽样集与扩展集对照**（题目硬性要求，`sample_vs_full_check.csv`）：

| 域 | A1 抽样 Q | A2/A3 全量 Q | 绝对差 |
|---|---|---|---|
| arxiv | 0.5318 (n=1,419) | 0.5315 (n=17,523) | 0.0003 |
| github | 0.5636 (n=10,000) | 0.5629 (n=203,752) | 0.0007 |

抽样与全量结果偏差 < 0.001，证明评分流程对样本量不敏感、抽样集代表性良好。

### 1.3 质量冲突：定义、成因与消解

**冲突定义（经迭代修正）**：初版"样本内 22 维定向分 P90−P10 ≥ 0.6"的极差定义在 7 个域上冲突率均 ≈100%，无区分度，弃用。修正后定义：

- 将 22 维分为**语义模型组**（fineweb_edu、fluency_en、modernbert×4、dsir×3、qurater，10 维）与**启发统计组**（ad_en + rps×11，12 维）；
- 组间分歧度 gap = |semantic_mean − heuristic_mean|；
- **强冲突**：gap ≥ 0.2102（A1 分布的 P90，即各域对照下的统一阈值）；
- 另记录典型成对冲突："高教育价值（P80↑）且高广告（P80↑）"。

**冲突率（A1 各域 + 扩展集检验）**（`conflict_by_domain_v2.csv`）：

| 域 | 强冲突率 | 扩展集对照 |
|---|---|---|
| book | **88.3%** | — |
| arxiv | 30.9% | A2 全量 34.8% ✓ |
| github | 19.5% | A3 全量 20.1% ✓ |
| wikipedia | 16.7% | — |
| stackexchange | 6.0% | — |
| commoncrawl | 1.7% | — |
| c4 | 1.5% | — |

扩展集上主要结论成立（arxiv/github 冲突率与抽样集一致），满足"冲突分析应覆盖抽样集，并在扩展集上检验"的要求。

**成因分析**（用原始 content 特征定位，`conflict_by_domain_v2.csv`、`content_validation_extremes.csv`）：

1. **格式符号干扰启发指标（arxiv）**：强冲突 arxiv 文档的 LaTeX 标记数中位数为 **1,520**，非冲突文档仅 **391.5**。大量 `\begin{}`、`$` 等非字母符号推高"非字母词占比""数字字符占比"等启发指标（被判为低质），而语义模型正确识别其学术价值——这是 arxiv 冲突率高的主因。
2. **文档长度饱和（book）**：冲突书籍文档字符中位数 **421,737** vs 非冲突 **51,832**。超长文档使词数/句数等长度类指标触顶截断，组内系统性偏离。
3. **指标离群定位**（`metric_outlier_contribution.csv`）：以"离样本中位定向分最远的指标"计，句数（29.8%）与词数（24.6%）是最常见的离群指标，即**超过半数冲突由长度类统计量引起**，与成因 1–2 互证。
4. **成对冲突（高教育价值 ∧ 高广告）**：全体占 4.96%，stackexchange 高达 17.6%——问答帖中推广性内容与知识性内容天然混杂。

**消解规则与效果**：采用**截尾鲁棒聚合**（去头尾各 4/22 维）作为消解后的综合分，其原理是冲突的本质是少数指标被格式/长度因素污染，截尾等价于自动降权污染指标。效果（`conflict_resolution_effect.csv`）：

- 全体样本 |ΔQ| 均值 0.024，Q_equal 与 Q_robust 的 Spearman = **0.990**——消解不改变整体排序，仅对冲突样本做局部修正；
- 域级排序完全不变（Spearman = 1.000）。评分对聚合规则稳健。

**原始内容检验评分可靠性**：按 Q 十分位统计原文特征（`content_validation_by_decile.csv`），字符中位数从最低十分位的 1,196 单调升至最高十分位的 19,537，数字字符占比从 1.48% 降至 0.18%——高分文本更长、更完整、噪声更少，与"质量"的语义一致，评分有效。

## 第二部分 领域配比建模

### 2.1 数据与预处理

配方实验（RegMix，A4–A15）：512 组训练配比（1M 规模）+ 检验集 1M/60M/1B（256/256/64 组）+ 外推表 10B/70B（各 63 组）。每行 17 域配比和 ∈ [0.996, 1.003]（千分位舍入），无负分量（`simplex_check.txt`），回归前按行重归一化。17 个训练域中 **nih_exporter、philpapers、enron_emails、europarl 无对应验证 Loss**（13 个 Loss 列），处理决策：保留其配比列作为自变量（其影响通过挤占其他域的份额间接体现），但不以其 Loss 为因变量——在报告中明确该 4 域的作用只能间接识别。

### 2.2 模型设定与检验

因变量为 13 个域的验证 Loss 及其均值。比较两类模型（`regression_validation.csv`、`gbm_validation.csv`）：

| 模型 | 检验集 test_1M R²（13 目标） | 平均Loss R² |
|---|---|---|
| Ridge 线性（α=1，处理单纯形共线性） | 0.35–0.77，均值 ≈0.57 | — |
| **梯度提升 GBM** | **0.966–0.993** | **0.9787** |

Ridge 的 5 折 CV R² 与检验集一致（无过拟合）；GBM 显著更优，说明配比→Loss 存在非线性与域间交互。**最终采用：GBM 作预测与寻优模型，Ridge 系数作边际解释**。

跨尺度外推（关键发现）：1M 拟合的模型直接预测 60M/1B 的 Loss 绝对水平时 R² 为大负数——**Loss 水平随模型尺度整体下移（1M 均值≈5.0、60M≈3.6、1B≈2.2），配比模型只应在同尺度内做绝对预测，跨尺度只能比较排序**。为此建立尺度无关模型：对每尺度内 Loss 做 z-score 标准化后合并训练，仅用 train_1M 训练、在各检验集上算排序相关（`cross_scale_consistency.csv`）：

| 检验集 | Spearman ρ（预测排序 vs 真实排序） | n |
|---|---|---|
| test_1M | **0.954** | 256 |
| test_60M | **0.928** | 256 |
| test_1B | **0.624** | 64 |

配比效果在 1M→60M 几乎完全保持，到 1B 仍有中等保持——**"小尺度学到的配比规律可向大尺度迁移，但保真度随尺度跨度衰减"**。

### 2.3 是否引入质量评分 Q 的论证

按 A16 映射表将域级 Q 引入：direct/near_direct 的 6 域（arxiv 0.531、github 0.563、stackexchange 0.520、wikipedia_en 0.541、gutenberg_pg_19 0.542、pile_cc 0.577）取问题一 Q，其余 11 个 inferred 域取均值 0.546 作缺省（`domain_Q_for_mixture.csv`），构造质量调整特征 p·Q 加入回归。结果：**13 个目标的检验 R² 变化 < 0.001**。结论：

1. The Pile 各域经过语料库构建时的清洗，域间 Q 差异小（0.52–0.58），且每个域的 Q 为常数，其效应已被域哑变量（配比系数）吸收；
2. 质量的作用体现在**语料构建（过滤）阶段**而非**配比阶段**；将 Q 留到问题二的广义标度律中作为独立因子引入更恰当。故配比模型不显式含 Q。

### 2.4 最优配比求解与验证

**目标**：min 13 域平均验证 Loss，s.t. Σpᵢ=1, pᵢ≥0。线性（Ridge）目标在单纯形上退化到角点解（100% ubuntu_irc，数学上必然但无实际意义），故用 GBM 目标 + SLSQP 多起点（40 个 Dirichlet 随机起点）求解，并用 20,000 个随机配比做全局验证。

**最优配比 p\***（`optimal_mixture_gbm.csv`，单域 ≤30% 的上限约束不起作用）：

| 域 | p\* | 域 | p\* |
|---|---|---|---|
| stackexchange | **0.178** | pubmed_abstracts | **0.148** |
| pile_cc | **0.147** | freelaw | **0.145** |
| uspto_backgrounds | 0.090 | wikipedia_en | 0.047 |
| pubmed_central | 0.044 | nih_exporter | 0.037 |
| enron_emails | 0.036 | philpapers | 0.031 |
| dm_mathematics | 0.028 | gutenberg_pg_19 | 0.017 |
| hackernews | 0.016 | arxiv | 0.014 |
| github | 0.009 | ubuntu_irc | 0.008 |
| europarl | 0.004 | | |

特点：问答（stackexchange）、摘要/专利/法律等结构化知识文本被加重；arxiv、github 等专项域被降权——与直觉相反但可解释：目标函数是 13 域**平均** Loss，加权通用知识域能同时改善多个验证域。

**寻优可靠性**（`optimization_verification.csv`）：GBM 目标面呈"高原"——p\* 的预测 Loss 4.722，在 20,000 个随机配比中居前 3.6%；均匀配比（4.698，前 0.6%）与全局随机最优（4.657）差距均在 1.4% 以内。**大量配比接近最优，配比微调收益有限但方向稳健**。

**实测验证**（在检验集中找与候选配比最近的配方，比较真实 Loss，`robustness_eval_gbm.csv`）：

| 候选 | test_1M 真实Loss(分位) | test_60M | test_1B | est_10B | est_70B |
|---|---|---|---|---|---|
| **p\*（优化）** | 4.843（**前 4.3%**） | 3.491（**前 3.5%**） | 2.182（前 15.6%） | 1.923（前 90.5%） | 1.541（前 87.3%） |
| 均匀配比 | 5.043（前 20.7%） | 3.576（前 12.1%） | 2.181（前 14.1%） | 1.957（前 95.2%） | 1.598（前 96.8%） |
| 训练集实测最优 | 5.035（前 19.1%） | 3.624（前 19.5%） | 2.233（前 57.8%） | 1.957（前 95.2%） | 1.598（前 96.8%） |

p\* 在真实检验集 1M/60M 上进入前 5%，明显优于均匀配比与训练集实测最优；迁移到 1B 仍在前 16%。

**外推稳健性讨论（A12–A15）**：在外推表 est_10B/70B 上，所有候选配比（含 p\*）都落在高 Loss 分位（≈90%），且 1M 模型预测排序与 est 排序呈**负相关**（Spearman −0.43/−0.47，`extrapolation_rank_stability.csv`）。分析：est 表 Loss 是从 1M/60M/1B 三尺度按幂律逐配方外推的**非观测数据**，外推放大了尺度间配比效应的差异，导致排序结构性反转。结合 2.2 中真实数据 1M→1B 保持良好（ρ=0.62–0.93）的事实，本文判断：**配比规律在真实外推中可信，而 est 表的排序反转应归因于外推数据本身的可信边界**，在论文中明确标注，不作为否定配比模型的证据。

### 2.5 领域影响分析

Ridge 平均边际系数与消融（`ridge_coefficients.csv`、`domain_ablation.csv`）：从均匀配比中移除某域导致的平均 Loss 上升幅度排序——ubuntu_irc（+0.054）、dm_mathematics（+0.040）、hackernews（+0.027）贡献最大；而移除 arxiv、freelaw、github 反而使平均 Loss 略降（−0.027 至 −0.032，即这些域占比高于其边际价值）。**注意**：ubuntu_irc 自身在 13 个验证域之内，纯域训练大幅降低其自身 Loss，存在自我评价偏差，解释时已剔除该效应后再比较。
