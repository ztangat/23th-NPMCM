全局 7 域 Q 均值 Q̄ = 0.6176。最终口径：

- **direct**（arxiv / github / stackexchange）：直接采用实测域级 Q（有同名质量域，无需估计），λ=1；
- **near_direct**（wikipedia_en / gutenberg_pg_19 / pile_cc）：`0.8×实测 + 0.2×核估计`，λ=0.8；
- **inferred**（其余 11 域）：只能用核估计，并按最近邻距离向 Q̄ 做保守收缩，`λ = 1 − d_min/(d_min+σ)`，`Q = λ·Q_kernel + (1−λ)·Q̄`。
